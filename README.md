# Device Security Scanner downloads

The newest version of Device Security Scanner for the field laptop. These links always give the newest build.

- Mac with Apple silicon (M1 or newer): https://github.com/jmlasorsa/device-security-scanner-releases/releases/latest/download/Device-Security-Scanner-Mac-Apple-silicon.pkg
- Mac with an Intel processor: https://github.com/jmlasorsa/device-security-scanner-releases/releases/latest/download/Device-Security-Scanner-Mac-Intel.pkg
- Windows PC: https://github.com/jmlasorsa/device-security-scanner-releases/releases/latest/download/Device-Security-Scanner-Windows-Setup.exe
- User guide (PDF): https://github.com/jmlasorsa/device-security-scanner-releases/releases/latest/download/Device-Security-Scanner-Guide.pdf

Not sure which Mac file? Apple menu > About This Mac shows "Chip: Apple M..." or "Processor: Intel".

Mac: double-click the downloaded file. The first time, macOS says it cannot verify it: click Done, open System Settings > Privacy & Security, scroll down and click Open Anyway. Then Continue and Install. The app is in the Applications folder.

Windows: double-click the Setup file. If Windows says "Windows protected your PC", click More info, then Run anyway. The app is in the Start menu and on the desktop.

The app asks for a password when it opens. Ask the person who sent you this page for it.

After the first install the app updates itself: it checks this page when it opens, tells you when a new version is ready, and installs it with one press. These links never change.
